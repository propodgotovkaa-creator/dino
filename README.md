# Тайны древнего мира

Интерактивная логопедическая экспедиция: четыре динозавра, 40 предъявлений слогов, постепенные раскопки и четыре сборки по восемь фрагментов.

## Запуск

Статический сайт без сборки и внешних сервисов. Откройте через HTTP, например `python3 -m http.server 8000`. Прямой `file://` не поддерживает ES-модули.

В GitHub: **Settings → Pages → Deploy from a branch → main → / (root) → Save**.
После публикации адрес: `https://propodgotovkaa-creator.github.io/dino/`.

## Встраивание в Genially

Добавьте внешний контент / iframe со ссылкой на опубликованную игру:

```html
<iframe src="https://propodgotovkaa-creator.github.io/dino/"
 title="Тайны древнего мира — раскопки динозавров"
 width="1280" height="720" style="border:0;aspect-ratio:16/9;width:100%;"
 allow="autoplay; fullscreen" allowfullscreen></iframe>
```

Задайте блоку соотношение 16:9. Если используете `sandbox`, разрешите `allow-scripts allow-same-origin`; формы, микрофон и камера игре не нужны. Звук запускается только после пользовательского действия. При недоступности localStorage игра продолжает работать, слоги сохраняются между раундами в текущем сеансе.

## Управление

Педагог вводит собственные слоги (пробелы, запятые, переводы строк). Регистр сохраняется. Пустой список не допускается; менее десяти слогов повторяются, из длинного списка используются первые десять. Перед каждым динозавром список можно изменить.

После чтения нажмите «Прочитали! Копаем». Водите кистью с нажатой кнопкой мыши или пальцем по указанной части раскопа. Слог появляется чёрным шрифтом на белом кружочке прямо на активном участке. После подтверждения чтения кружочек исчезает и можно расчищать землю. Подсказка и мягкое светлое пятно указывают активную область. Границы не нарисованы. Раскопки идут по верхней половине слева направо, затем по нижней справа налево. Для завершения достаточно расчистить 60% грунта над самой костью: землю вокруг вычищать не нужно, она плавно исчезает за 500 мс. Если в краевом участке кости нет, достаточно короткого движения кистью (6% поверхности).

На этапе сборки берите детали из нижнего лотка и совмещайте с образцом. Детали фиксируются в пределах 68 единиц игровой сцены. Ошибки не ограничены. Вся ячейка лотка доступна для захвата, включая тонкие фрагменты хвоста. Слоги и переключатель звука сохраняются локально; аудиозапись и распознавание речи отсутствуют.

## Реализация

- `index.html`, `style.css`, `game.js`: экраны и взаимодействие.
- `model.js`: правила слогов, анатомическое разделение изображений и участки земли.
- `assets/`: локальная реалистичная графика WebP с сохранённым альфа-каналом.
- Canvas: два стираемых слоя грунта, мягкая кисть, пыль, оценка остаточной непрозрачности.
- Pointer Events: захват указателя, отмена жеста, преобразование координат при масштабировании.
- Web Audio: негромкий шорох и сигналы находки/установки; внешних аудиофайлов нет.

## Проверки

`npm test` — чистые правила игры. `npm run test:engine` — полный сценарий 4 × 10 раскопок и 4 × 8 установок на настоящем Canvas; для него установите `@napi-rs/canvas` (`npm install`) либо укажите путь через `CANVAS_MODULE`.

Интеграционный тест проверяет блокировку кисти, порог очистки, сохранение масок после изменения размера, неверное размещение, переходы раундов, музей и повторную игру. В браузере отдельно проверены форма, стирание движениями мыши, переход после десяти участков и притягивание деталей. Проверка в реальном редакторе Genially требует доступа к конкретной презентации; сама игра не задаёт запретов на iframe.

Графика — сгенерированные художественные реконструкции, а не фотографии реальных музейных экспонатов. Детали делятся из того же изображения, которое открывается под грунтом. Это логопедическая игра, не научный анатомический атлас.
